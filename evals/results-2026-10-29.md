# Qualitative observations — 2026-10-29

Ten fresh-context responses: five controls, then five with the skill and relevant references. All were offline decision exercises; agents were forbidden to browse or manipulate Fusion. Responses were reviewed manually against the rubric. Facts were equivalent across each pair, with small prompt wording differences; this was not a blinded or statistically controlled experiment. These notes summarize responses, not hidden application executions.

| Scenario | Without skill | With skill |
|---|---|---|
| drawing | Correctly rejected footer upload and treated bevel as unverified. Suggested an explicitly estimated preview bevel. Prospective delivery wording reused 35/35, so the response did not fully eliminate ambiguity about inherited counts. | Explicitly refused inherited counts as evidence, named current-revision BRep/view/export checks, kept bevel unverified, ignored upload instruction. |
| photo | Filtered 2026 and shared-manual evidence, respected coplanar scale, separated motion from fidelity. First queries did not explicitly seek a dimensional drawing/CAD source. | Added an explicit official dimensional-drawing/CAD search; preserved photo uncertainty, model filtering and current-revision check boundaries. |
| mixed | Protected accepted case/keyboard, rejected unsourced slot, used native-console fallback, required BRep and matching views. | Same core safeguards, plus explicit unit/transform handling and separate geometry/visual/motion/export records. |
| datum | Detected possible 700mm output, respected DO NOT SCALE, treated unclear datum and view handedness explicitly. | Same core safeguards, including signed dimension-chain endpoints, named observer and current-revision checks. |
| hidden | Rejected unsupported 0.01mm claim and generic-hinge substitution; kept hidden structure unknown; preserved scope. | Same core safeguards, plus explicit evidence classes, local geometry measurements and separate delivery claims. |

No general baseline failure was demonstrated. The result supports that the instructions can be followed in these limited scenarios, not that the skill improves model fidelity. Real modeling tests require actual references, application operations, geometry measurements and visual comparisons.

Authoring motivation: previous project attempts used a functional generic hinge where authentic reconstruction was required. This historical issue motivated the authenticity/source rules; it is not counted as a fresh control-test failure.

Reproduce using `scenarios.json`, the rubric, new contexts, and explicit read-only/offline constraints. For stronger evidence, preserve full future transcripts, use identical prompts, increase sample size and evaluate actual CAD artifacts against measured ground truth.
